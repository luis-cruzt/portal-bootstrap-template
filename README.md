# Portal Bootstrap Template

A modern, production-ready full-stack React application template built with TanStack Start.

```
┌─────────────────────────────────────────────────────────┐
│  TanStack Start  ·  React 19  ·  TypeScript  ·  Vite 7  │
│  Tailwind CSS 4  ·  Shadcn/UI  ·  Nitro  ·  Vitest      │
└─────────────────────────────────────────────────────────┘
```

## Features

- **Full-stack SSR** — TanStack Start with file-based routing and server functions
- **Server-side auth** — HTTP-only session cookies, zero tokens in the browser
- **API proxy pattern** — server functions inject auth headers; the client never touches tokens
- **Role-based access control** — route-level guards via `beforeLoad`
- **Type-safe everything** — TypeScript strict mode, Zod validation, typed routes
- **Beautiful UI** — Shadcn/UI components with light/dark theme support
- **Testing ready** — Vitest + React Testing Library, pre-configured
- **Containerized** — multi-stage Dockerfile included

## Getting Started

### 1. Clone and install

```bash
git clone <your-repo>
cd portal-bootstrap-template
npm install
```

### 2. Configure environment

```bash
cp .env.example .env
```

Edit `.env`:

```env
API_BASE_URL=http://localhost:3000/api/v1
SESSION_SECRET=your-secret-key-minimum-32-characters-long
NODE_ENV=development
```

> The `SESSION_SECRET` must be at least 32 characters. Generate one with:
>
> ```bash
> openssl rand -base64 32
> ```

### 3. Start development server

```bash
npm run dev
```

Open [http://localhost:3001](http://localhost:3001).

## Authentication Architecture

All authentication is handled **server-side**. The browser never sees a token.

```
Browser                 TanStack Start Server          Backend API
  │                            │                           │
  │  POST /login (form)        │                           │
  │ ─────────────────────────► │                           │
  │                            │  POST /auth/login         │
  │                            │ ─────────────────────────►│
  │                            │  ◄── { access_token }    │
  │                            │                           │
  │                            │  decode JWT, store in     │
  │                            │  HTTP-only session cookie │
  │  ◄── Set-Cookie (session)  │                           │
  │                            │                           │
  │  GET /dashboard            │                           │
  │ ─────────────────────────► │                           │
  │                            │  read session cookie,     │
  │                            │  validate token, check    │
  │                            │  role, serve or redirect  │
  │  ◄── 200 / 302            │                           │
  │                            │                           │
  │  apiClient.get('/tickets') │                           │
  │ ─────────────────────────► │                           │
  │                            │  inject Bearer token      │
  │                            │ ─────────────────────────►│
  │                            │  ◄── data                │
  │  ◄── data                  │                           │
```

### Server functions

| Function            | Method | Description                     |
| ------------------- | ------ | ------------------------------- |
| `loginFn`           | POST   | Authenticate, store session     |
| `logoutFn`          | POST   | Clear session cookie            |
| `getCurrentUserFn`  | GET    | Read + validate session         |
| `hasRequiredRoleFn` | GET    | Check role (ADMIN=2, SUPPORT=4) |
| `apiProxyFn`        | POST   | Proxy requests with auth header |

### Session configuration

Sessions expire after **20 minutes** of inactivity. The `useIdleTimeout` hook can trigger auto-logout in the browser. Configure in `src/utils/session.ts`.

## Adding a New Protected Route

1. Create the route file:

```typescript
// src/routes/_authenticated/tickets.tsx
import { createFileRoute } from '@tanstack/react-router'
import { useQuery } from '@tanstack/react-query'
import apiClient from '@/lib/api-client'

export const Route = createFileRoute('/_authenticated/tickets')({
  component: TicketsPage,
})

function TicketsPage() {
  const { data, isLoading } = useQuery({
    queryKey: ['tickets'],
    queryFn: () => apiClient.get('/tickets'),
  })

  if (isLoading) return <div>Loading...</div>

  return <div>{/* render tickets */}</div>
}
```

2. The route is automatically protected — `_authenticated.tsx` checks auth and role in `beforeLoad`.

3. Add to sidebar navigation in `src/components/app-sidebar.tsx`.

## Connecting to Your Backend

1. Set `API_BASE_URL` in `.env`
2. Update `src/types/auth.ts` to match your JWT payload structure
3. Adjust role values in `hasRequiredRoleFn` (`src/server/auth.ts`) for your roles
4. Update `loginFn` if your auth endpoint returns a different shape
